# Questão 5

Explique a diferença entre Épico, História de Usuário e Tarefa.

```text
Resposta Questão 5: 
- Épico: Uma funcionalidade grande que precisa ser dividida em partes para ser desenvolvida, ou seja a Funcionalidade em si.
- História de Usuário: Uma necessidade do usuário descrita.
- Tarefa: A atividade necessária para os desenvolvedores implementar.
```

O que é uma branch no Git e qual sua finalidade?

```text
Resposta Questão 7: Uma branch é uma ramificação dentro do repositório. A finalidade é permitir que o desenvolvedor trabalhe de forma isolada, garantindo que o código principal não seja alterado ou quebrado durante o processo.
```

# Questão 9

Explique o que é gerenciamento de configuração.

```text
Resposta Questão 9: É a prática de controlar e organizar as mudanças nos artefatos de software, ele garante que a equipe saiba qual versão do sistema está em uso, evita conflitos de código entre desenvolvedores e permite reverter o projeto para um estado anterior se acontecer falhas. 
```
